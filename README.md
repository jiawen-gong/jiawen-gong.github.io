# Jiawen Gong — Personal Website

Personal academic and professional homepage for **Jiawen Gong**, an undergraduate in Mathematics & Computer Science at the University of Illinois Urbana-Champaign.

**Website:** https://jiawen-gong.github.io/

## Updating the site

- Edit `index.html` to update the biography, publications, work experience, or contact details.
- Edit `styles.css` to change the appearance. Layouts for desktop, mobile, print, and reduced motion are included.
- Replace `Jiawen_Gong_Resume.pdf` with a newer resume, keeping the same filename.
- Update the footer date when making content changes.

This is a static website. There is no build step, framework, package installation, analytics, or backend. The page also works without JavaScript.

## GitHub Pages

The repository must be named `jiawen-gong.github.io` under the `jiawen-gong` account. Publish from **Settings → Pages → Deploy from a branch → main → / (root)**.
